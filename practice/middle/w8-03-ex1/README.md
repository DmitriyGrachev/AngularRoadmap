# Компонент строки и изолированные DI-области

Ручное задание к уроку [w8-03](../../../content/lessons/w8-03.md). Выделить отображение заявки с явным input/output и доказать независимость локального состояния двух панелей.

## Где работать

Реализация находится в вашей версии `practice/workplace`: src/app/list-page.ts/html, новый компонент строки, панель выбора, store и их spec-файлы. Эта папка задания хранит только условия и `notes.md` с доказательствами. Наличие заполненных заметок само по себе не подтверждает работу функции. Не заменяйте свои исходники авторским решением; сохраните предыдущие выполненные изменения.

```text
npm.cmd run practice:workplace
npm.cmd run test:workplace
npm.cmd run build:workplace
```

Адрес: http://127.0.0.1:4305. DeskApi — асинхронный сервис в памяти: запросов GET/PATCH в Network нет, reload восстанавливает seed. Для порядка и числа операций используйте управляемый fake API или spy. Это не проверка HTTP, БД или двух серверных клиентов. Страница начинается с 1, статусы — open/in-progress/closed; не переносите контракт middle-04 без адаптации.

## Требования

1. Компонент строки получает данные и сообщает одно событие выбора; запрос и URL остаются у страницы.
2. Новая панель хранит максимум три выбранных ID, показывает счётчик и очистку.
3. Provider store находится у владельца панели. Её вложенный счётчик использует тот же экземпляр.
4. Две панели независимы; уничтоженная и созданная заново панель начинает пустой.
5. Сохраняются ссылки, имена действий, формат даты, статусы, приоритет и адаптивность.

## Проверка на новых данных

- Выбор в первой панели при пустой второй.
- Одинаковый ID в обеих; очистка только первой.
- Уничтожение и повторное создание первой панели.
- Новый title через input без пересоздания списка.

До кода запишите ожидаемое поведение, затем реализуйте и сравните результат. Если временные свойства проверяются тестом, управляйте завершением операций вручную; случайные задержки не доказывают отсутствие гонки. Baseline-тесты не являются оценкой новой функции.

## Что сохранить в notes.md

Карта imports/providers, компонентный тест двух настоящих панелей с Angular DI и подтверждение единственного события выбора. Укажите команды и фактический результат, а также ограничения. Не копируйте служебные исходники и реальные данные работодателя.

Обязательные свойства нельзя компенсировать красивым интерфейсом или количеством тестов. Полные критерии и три последовательные подсказки находятся в уроке.
