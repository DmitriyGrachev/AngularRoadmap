# Не дублировать сохранение при повторном клике

Урок w5-03, около 35 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

Для записи отмена клиентской подписки не доказывает отмену серверного действия. exhaustMap принимает первую команду и игнорирует новые, пока внутренний поток не завершится. Это похоже на busy-guard вокруг Java async-команды. Защита действует в клиентском потоке, а не обеспечивает exactly-once на сервере.

### Контракт API

saveOnce(clicks$,save) возвращает Observable. Событие clicks$ — payload заявки; save(payload):Observable<Issue>. Пока save активен, следующие payload игнорируются, не ставятся в очередь и не отменяют запись. Успех → {kind:"saved",issue}; Error → {kind:"error",message:error.message}; неизвестная ошибка → "Ошибка сохранения". Ошибки обрабатываются внутри операции, следующий клик снова вызывает save. Принятый payload передаётся без изменений.

### Пример и новая проверка

A, B во время сохранения A, C после завершения: save вызван для A и C. Новый пример: после ошибки первый следующий клик должен пройти.

### Работа

Из корня проекта выполните `npm.cmd run learn -- check checks-14`. Редактируйте только `practice/checked/checks-14/solution.mjs`. Сначала запишите прогноз или собственную попытку в тренажёре. Отчёт сохраняется в practice/reports и не отмечает урок освоенным автоматически.

## Условия приёмки

- Максимум одна активная запись, busy-клики игнорируются.
- Успех и ошибка представлены значениями.
- После отказа доступен повтор без пересоздания потока.

## Проверка

1. Запустите исходный вариант и прочитайте конкретные провалы.
2. Исправьте файл решения, сохранив экспортируемый API.
3. Повторите запуск и добавьте собственный пример из описания.
4. Запишите объяснение механизма в тренажёре; там доступны три последовательные подсказки.

Проверки выполняют функции на новых данных. TypeScript-задачи компилируют отдельного потребителя, Angular-задачи используют настоящие API установленных пакетов. Файлы эталонов и отчётов отделены от решения ученика.

`starter.mjs` — сохранённый исходный образец для проверки платформы. Работайте в `solution.mjs`: решённое упражнение не должно ломать общие тесты курса.
