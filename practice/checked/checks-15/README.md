# Начать Promise параллельно и сохранить порядок

Урок w2-02, около 25 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

await в цикле начинает следующее чтение после предыдущего. Для независимых чтений создайте все Promise, затем ждите их вместе. Promise.all сохраняет позиции исходного массива независимо от скорости сети. Это близко к CompletableFuture.allOf, но JavaScript сразу собирает упорядоченный массив. Речь об одновременном ожидании I/O, не о нескольких CPU-потоках.

### Контракт API

async loadDashboard(ids,load) принимает строки id и load(id):Promise<Issue>. Вызовите load для всех id синхронно до ожидания любого результата; верните Promise массива в порядке ids. Пустой ids → [] без вызова load. Отказ любого Promise отклоняет общий результат той же ошибкой, не отменяя остальные операции. Повторяющиеся id означают отдельные вызовы. load по контракту возвращает Promise, синхронные throw вне задачи.

### Пример и новая проверка

ids=[A,B,C], завершения C,A,B → результат [A,B,C]. Новый пример: [A,A] вызывает два чтения, дедупликация здесь не требуется.

- Все чтения стартуют до завершения первого.

- Пустой ввод и отказ соблюдают контракт.
