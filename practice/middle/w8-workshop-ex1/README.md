# Подборка для разбора как Angular feature

Ручное задание к уроку [w8-workshop](../../../content/lessons/w8-workshop.md). Добавить подборку максимум трёх заявок текущей страницы, сохранив URL-состояние и явное владение временными данными.

## Где работать

Реализация находится в вашей версии `practice/workplace`: src/app/list-page.ts/html, компоненты подборки, store и связанные проверки. Эта папка задания хранит только условия и `notes.md` с доказательствами. Наличие заполненных заметок само по себе не подтверждает работу функции. Не заменяйте свои исходники авторским решением; сохраните предыдущие выполненные изменения.

```text
npm.cmd run practice:workplace
npm.cmd run test:workplace
npm.cmd run build:workplace
```

Адрес: http://127.0.0.1:4305. DeskApi — асинхронный сервис в памяти: запросов GET/PATCH в Network нет, reload восстанавливает seed. Для порядка и числа операций используйте управляемый fake API или spy. Это не проверка HTTP, БД или двух серверных клиентов. Страница начинается с 1, статусы — open/in-progress/closed; не переносите контракт middle-04 без адаптации.

## Требования

1. Повторный выбор снимает заявку; четвёртая новая заявка не добавляется, лимит объяснён.
2. Выбор хранится по ID, счётчик и строки выводятся из актуальных данных.
3. Смена страницы/фильтра очищает подборку. Refresh и возврат с карточки начинают пустую подборку.
4. Фильтры и страница восстанавливаются из URL при прямом входе и Back/Forward.
5. Строка не обращается к API; один store обслуживает feature; независимые экземпляры не разделяют выбор.

## Проверка на новых данных

- Прямой URL второй страницы, выбор двух строк.
- Смена status и Back: фильтр восстановлен, подборка пуста.
- Новый title выбранной строки в управляемом ответе.
- Два экземпляра feature с независимым выбором.

До кода запишите ожидаемое поведение, затем реализуйте и сравните результат. Если временные свойства проверяются тестом, управляйте завершением операций вручную; случайные задержки не доказывают отсутствие гонки. Baseline-тесты не являются оценкой новой функции.

## Что сохранить в notes.md

Карта URL→данные→представление и событие→команда, store-тест инвариантов, компонентный тест события и проверка реальной навигации. Укажите команды и фактический результат, а также ограничения. Не копируйте служебные исходники и реальные данные работодателя.
