# bug-05: Экран закрыт, внутренний таймер продолжает работать

Связанный урок: [w3-04](../../../content/lessons/w3-04.md). Около 35 минут; упражнение может заменить часть ручной практики урока.

Симптом: после уничтожения компонента события таймера продолжаются. Выполните node practice/bug-lab/bug-05/repro.mjs: start в 0 мс, destroy в 35 мс, шаг — 10 мс. Ожидаются 0, 1, 2 и завершение; до правки видны более поздние значения. Виртуальное время повторяет дефект без реального ожидания. Исправьте границу освобождения всей цепочки.

## Запуск из корня проекта

```powershell
node practice/bug-lab/bug-05/repro.mjs
npm.cmd run learn -- check bug-05
```

Сценарий работает без сайта, dev server и Java API с установленными зависимостями проекта. Исходный дефект намеренно завершает repro с AssertionError и ненулевым кодом. После исправления сценарий завершается успешно. Полная проверка создаёт отчёт версии 1 для учебного сайта.

Редактируйте только `solution.mjs`. `starter.mjs` сохраняет исходную поломку для проверки качества задания и не зависит от вашего решения. Существующее приложение ученика не используется и не переписывается.

## Контракт

ticks(start$, destroy$, scheduler) возвращает Observable<number>. start перезапускает interval(10, scheduler), destroy прекращает всю цепочку.

## Критерии результата

- После destroy в 35 мс нет событий в 40 мс и позже, цепочка завершена.
- Новый start заменяет предыдущий отсчёт; одновременно работает один таймер.
- Освобождение работает и после повторного start; параметр scheduler сохранён.

## Диагностика

Перед изменением запишите ожидаемое и фактическое поведение, гипотезу причины и эксперимент, различающий две возможные причины. После исправления запустите полную проверку, а не только один repro. Три последовательные подсказки и объяснение находятся в тренажёре; сначала сохраните собственную попытку.

## Новый регрессионный пример

Регрессионная задача: start в 0 мс, повторный start в 25 мс, destroy в 47 мс. Ожидайте 0, 1, 0, 1. Проверьте завершение цепочки, а не только количество внешних событий.
