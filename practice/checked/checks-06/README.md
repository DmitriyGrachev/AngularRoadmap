# Восстановить фильтр из URL и очистить defaults

Урок w4-05, около 35 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

Query-параметры — внешний строковый ввод. parseInt принимает начало "4x", что слишком мягко для номера страницы. Проверяйте весь формат. URLSearchParams выполняет правильное кодирование, как специальные URL-строители Java. Конкатенация q="A&B" вручную создаст лишний параметр. При записи сохраняйте параметры других функций и hash.

### Контракт API

readFilters(absoluteUrl) → {q,status,page}; q trim, отсутствующее q → ""; status ALL/OPEN/IN_PROGRESS/DONE, неизвестный → ALL. page — строка только десятичных цифр, дающая безопасное неотрицательное целое, иначе 0. writeFilters(absoluteUrl,state) принимает валидное состояние, trim q, записывает q/status/page, удаляет defaults ""/ALL/0, сохраняет pathname, остальные параметры и hash, возвращает абсолютный URL.

### Пример и новая проверка

?status=DONE&page=4x восстанавливается в {q:"",status:"DONE",page:0}. Новый пример: q="A&B+" должен пройти запись/чтение без потери символов.

## Условия приёмки

- Неверные status/page заменяются defaults.
- Кириллица, &, + и пробелы корректно восстанавливаются.
- Сброс сохраняет sort и #list.
