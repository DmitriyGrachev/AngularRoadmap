# bug-09: PATCH потерял ID из отключённого поля

Связанный урок: [w5-05](../../../content/lessons/w5-05.md). Около 25 минут; упражнение может заменить часть ручной практики урока.

Симптом: редактор показывает правильный ID, но сервер не получает его в запросе. Выполните node practice/bug-lab/bug-09/repro.mjs: отключённый id присутствует в control, однако toUpdate возвращает только title. Найдите, почему наличие control не гарантирует наличие поля в form.value. Исправьте сериализацию, сохранив disabled у ID.

## Запуск из корня проекта

```powershell
node practice/bug-lab/bug-09/repro.mjs
npm.cmd run learn -- check bug-09
```

Сценарий работает без сайта, dev server и Java API с установленными зависимостями проекта. Исходный дефект намеренно завершает repro с AssertionError и ненулевым кодом. После исправления сценарий завершается успешно. Полная проверка создаёт отчёт версии 1 для учебного сайта.

Редактируйте только `solution.mjs`. `starter.mjs` сохраняет исходную поломку для проверки качества задания и не зависит от вашего решения. Существующее приложение ученика не используется и не переписывается.

## Контракт

createEditForm({ id, title }) возвращает FormGroup с disabled id. toUpdate(form) возвращает DTO { id, title }; валидность до отправки проверяет вызывающая оболочка.

## Критерии результата

- DTO содержит текущие id и title, даже когда ID отключён.
- Получение DTO не включает control и не меняет состояние формы.
- Полученный DTO остаётся снимком после дальнейшего изменения title.

## Диагностика

Перед изменением запишите ожидаемое и фактическое поведение, гипотезу причины и эксперимент, различающий две возможные причины. После исправления запустите полную проверку, а не только один repro. Три последовательные подсказки и объяснение находятся в тренажёре; сначала сохраните собственную попытку.

## Новый регрессионный пример

Регрессионная задача: добавьте отключённое поле версии и решите по контракту, нужно ли включить его в DTO. Для текущего решения проверьте пустой title и изменение поля после создания DTO: снимок должен остаться прежним.
