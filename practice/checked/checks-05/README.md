# Собрать PATCH только из изменённых полей

Урок w5-05, около 35 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

Полный объект формы и PATCH имеют разный смысл: отсутствие assignee оставляет прежнее значение, null снимает исполнителя. Поэтому нельзя удалять все falsy-значения. В Java для такого DTO часто нужно отдельное представление отсутствия поля. Partial в TypeScript делает поля optional, сохраняя их типы.

### Контракт API

Экспортируйте IssueDraft={title:string;priority:"LOW"|"NORMAL"|"HIGH";assignee:string|null}, IssuePatch=Partial<IssueDraft> и buildPatch(before,after):IssuePatch. Сравнивайте title после trim обоих входов, пишите trimmed title. Остальные поля сравниваются напрямую. Добавляйте только изменённые поля, сохраняйте null, не меняйте вход. Типы должны отклонять произвольный priority и id.

### Пример и новая проверка

Из {title:"A",priority:"LOW",assignee:"u1"} в {title:" A ",priority:"HIGH",assignee:null} получится {priority:"HIGH",assignee:null}. Новый пример: изменение только пробелов даёт {}.

### Работа

Из корня проекта выполните `npm.cmd run learn -- check checks-05`. Редактируйте только `practice/checked/checks-05/solution.ts`. Сначала запишите прогноз или собственную попытку в тренажёре. Отчёт сохраняется в practice/reports и не отмечает урок освоенным автоматически.

## Условия приёмки

- PATCH содержит только изменённые разрешённые поля.
- null снимает исполнителя; нормализуется только title.
- Strict-типы отклоняют id и неизвестный priority.
