# Запуск и работа с платформой

Все команды выполняются из корня `C:\ProjectsDirectory\Angular`. Не нужен глобальный Angular CLI: команды используют локальные зависимости из lockfile.

## Один раз

Проверьте `node --version` и `npm.cmd --version`. Проверенная версия Node — 22.23.2; минимальная в ветке 22 — 22.22.3. Другие совместимые ветки указаны в `package.json` (`engines`). При несовместимой версии установите подходящий Node из официального дистрибутива или своего менеджера версий, заново откройте терминал и выполните `npm.cmd ci`.

`npm.cmd ci` устанавливает зафиксированные зависимости и требует сеть. JDK понадобится с недели 4, а сайт и задания первых недель работают без него.

## Что запускать

Каждый сервер работает в отдельном терминале. Выключайте ненужные Ctrl+C.

| Команда | Адрес | Когда нужна |
|---|---|---|
| `npm.cmd run site` | http://127.0.0.1:4300 | Чтение уроков, роадмап, прогресс |
| `npm.cmd run practice:web` | http://127.0.0.1:4301/foundations/ | Браузерные примеры и задачи недель 1–2 |
| `npm.cmd run practice:angular` | http://127.0.0.1:4302 | Ваш проект недель 3–6 |
| `npm.cmd run practice:api` | http://127.0.0.1:8080/api/issues | Java API с недели 4 |
| `npm.cmd run practice:demo` | http://127.0.0.1:4303 | Отдельный эталон для разбора |
| `npm.cmd run practice:labs` | http://127.0.0.1:4304 | Небольшие разобранные примеры Angular |

Сайт курса и ученический Angular-проект собираются отдельно. Ошибка синтаксиса в своей практике не должна мешать читать урок, получать подсказки или экспортировать прогресс.

Для обычных HTML/JS-файлов сохраняйте файл в IDE и обновляйте страницу. Angular автоматически пересобирает изменения. Консоль и вкладка Network открываются через инструменты разработчика браузера, обычно F12.

## Отчёт проверки из IDE

1. В уроке найдите ID автоматического упражнения и его команду.
2. Запустите команду в корне проекта.
3. Прочитайте результат. Код выхода 1 у незавершённого упражнения ожидаем.
4. Откройте «Прогресс» → «Импорт JSON» и выберите **файл, указанный этим запуском**, из `practice/reports`.
5. Проверьте предварительный результат и подтвердите объединение.

Автоматический импорт предусмотрен для 41 задания: `w1-04-ex1`, `checks-01`…`checks-16`, `bug-01`…`bug-12` и `middle-01`…`middle-12`. Команда каждого задания находится в разделе «Практика» и в его README. Остальная практика и рабочие тикеты имеют ручные критерии. Сайт не запускает команды в IDE сам.

На роадмапе можно выбрать «Основы · 1–6» или «Продвинутый · 7–12». Полный маршрут — 60 занятий, 180 часов. Для второго этапа не нужен новый сайт или отдельная установка: используйте те же команды. Задания находятся в `practice/middle`; [подробная инструкция](../practice/middle/README.md) объясняет проверяемые упражнения и ручную работу в учебных приложениях.

Для шести рабочих тикетов запустите `npm.cmd run practice:workplace` и откройте `http://127.0.0.1:4305`. Это отдельное работающее приложение с асинхронным API в памяти. Перезагрузка восстанавливает исходные 18 заявок.

В «Журнале ошибок» есть отдельный экспорт попыток лаборатории, ошибок и повторений. Для переноса всего обучения сохраните оба файла: экспорт на странице «Прогресс» и экспорт журнала. При повреждённом хранилище сайт сохраняет исходные данные и предлагает их скачать; новые записи доступны в текущей вкладке и тоже экспортируются.

## Если что-то не работает

- **`npm.ps1` заблокирован.** Используйте именно `npm.cmd`. Изменять политику PowerShell не требуется.
- **Адрес не открывается.** Убедитесь, что соответствующий процесс ещё запущен и в его терминале нет ошибки. Используйте `127.0.0.1` и правильный порт из таблицы.
- **Порт занят.** Вероятно, сервер уже работает. Сначала откройте его адрес; либо остановите прежний процесс в его терминале. Не запускайте второй API одновременно на 8080.
- **Ошибка Angular-компиляции.** Прочитайте первое сообщение и путь файла в терминале практики. Сайт уроков остаётся доступным на 4300.
- **Запросы `/api` завершаются ошибкой.** Запустите Java API. Angular пересылает `/api` через dev proxy на 8080. В адресах HttpClient используйте `/api/issues`, а не адрес страницы учебного сайта.
- **`java` не найден или слишком старый.** Проверьте `java --version`: нужен JDK 21 в PATH. Maven устанавливать не требуется.
- **Первый запуск Java API не загрузил Gson.** Launcher обращается к Maven Central и проверяет SHA-256. Проверьте сеть; повторите запуск. Кэш лежит в `.cache/issue-api`.
- **JSON не импортируется.** Используйте полный файл отчёта или экспорта. Неизвестные версии схемы, неполные успешные проверки и чужие ID отклоняются. Старый отчёт текущего упражнения перепроверьте, если редакция задания изменилась.
- **Браузер сообщил об ошибке сохранения.** Экспортируйте текущий прогресс до закрытия вкладки. При повреждённом старом хранилище доступна отдельная загрузка исходных данных; они не перезаписываются молча.

## Данные

Java API хранит заявки в памяти. После его перезапуска возвращаются 32 исходные записи. Это удобно для повторяемой практики; созданные заявки не являются постоянной базой.

Сайт хранит прогресс в localStorage. У `localhost`, `127.0.0.1`, другого порта и другого профиля браузера разные хранилища. Для переноса используйте экспорт и импорт.

Для технической проверки рабочего примера при запущенных API, student и demo: `node author/solutions/issue-tracker/verify.mjs`. Браузерные проверки работают в отдельном профиле и не отмечают ваше обучение пройденным.
