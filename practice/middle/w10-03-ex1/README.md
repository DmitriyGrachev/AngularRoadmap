# w10-03-ex1: Собственный контрол и доступный диалог

180 минут. Основные условия и рубрика: [урок](../../../content/lessons/w10-03.md#criteria).

Создайте standalone CVA-контрол выбора приоритета и диалог в текущем issue-tracker. В workplace сделайте локальную демонстрацию: baseline не сохраняет priority. Программный write не вызывает пользовательский change; blur сообщает touched; disabled действует на настоящий input/select. Проверьте label, ошибки, открытие клавиатурой, Tab/Shift+Tab, Escape и возврат фокуса.

Новые сценарии: reset в null, два setValue, disabled до открытия, удаление вызывающей строки, ширина 360px. Для Material/CDK/Bootstrap сопоставьте эти обязанности с рабочей обёрткой, если библиотека уже есть; обязательный вариант использует native control/dialog без установки пакетов.

## Рабочая среда

Этот каталог хранит ваш отчёт notes.md. Реализацию делайте в собственной текущей версии practice/issue-tracker или practice/workplace, после точки восстановления; тренажёр не сбрасывает старые решения. Для Java-интеграции нужен настоящий backend из задания, не mock. Выбранный путь и ограничения запишите в notes.md.

Запуск из корня: npm.cmd run practice:angular (4302) либо npm.cmd run practice:workplace (4305). Проверки: npm.cmd run practice:test -- --watch=false либо npm.cmd run test:workplace. Исходный JDK API запускается npm.cmd run practice:api; команды вашего расширенного Spring API запишите отдельно.

## Проверка

Ручная оценка, без автоматического зачёта через learn check. До запуска запишите прогноз, затем фактический результат на новых данных. Приложите местоположение изменения, воспроизведение ошибки и объяснение границ проверки. Не помещайте пароли, cookie или token в отчёт.
