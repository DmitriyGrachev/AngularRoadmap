# Неделя 1: браузер и JavaScript

Работайте в корне репозитория. Запуск статических страниц:

```powershell
npm.cmd run practice:web
```

Сервер отдаёт каталог `practice` на `http://127.0.0.1:4301`.
Например, заготовка первого задания:
`http://127.0.0.1:4301/foundations/web-basics/w1-01-ex1/index.html`.

`examples` содержит завершённые демонстрации. Каталоги `w1-...-ex1` — самостоятельные заготовки с TODO, которые нужно выполнить самому. Изменения в примерах не подменяют работу над упражнением. Файлы сохраняются в IDE; после сохранения обновите страницу браузера.

Большинство заданий оцениваются вручную по рубрике в уроке. Автоматическое упражнение по массивам находится отдельно: `practice/foundations/w1-04-ex1`. Его единственная команда проверки: `npm.cmd run learn -- check w1-04-ex1`. Обычный вывод Console не является импортируемым отчётом курса.
