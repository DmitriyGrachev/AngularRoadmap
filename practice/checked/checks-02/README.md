# Проверить JSON до допуска в приложение

Урок w2-04, около 35 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

JSON.parse проверяет синтаксис, но может вернуть null или объект с неверными полями. Сначала проверьте контейнер, затем метаданные и каждый элемент. TypeScript assertion не похож на Jackson с валидацией: он исчезает при выполнении. Даже Java DTO на сервере не гарантирует правильного ответа сети или mock.

### Контракт API

parseIssuePage(text) → {ok:true,value:page} либо {ok:false,error:"invalid-json"|"invalid-shape"}. page={items:Issue[],total:number}; total — безопасное неотрицательное целое не меньше items.length. Каждый Issue — объект с непустыми после trim строками id/title и status OPEN/IN_PROGRESS/DONE. Массивы/null вместо объектов запрещены. Дополнительные поля допустимы и сохраняются; строки не нормализуются. Плохой ввод не бросает исключение.

### Пример и новая проверка

{"items":[],"total":0} допустим, total:"0" — ошибка формы. Новый пример: total=1 при двух заявках отклоняется.

### Работа

Из корня проекта выполните `npm.cmd run learn -- check checks-02`. Редактируйте только `practice/checked/checks-02/solution.mjs`. Сначала запишите прогноз или собственную попытку в тренажёре. Отчёт сохраняется в practice/reports и не отмечает урок освоенным автоматически.

## Условия приёмки

- Различаются ошибки синтаксиса и структуры.
- Проверяется каждый элемент, тип и диапазон total.
- Пустая страница и дополнительные поля поддерживаются.

## Проверка

1. Запустите исходный вариант и прочитайте конкретные провалы.
2. Исправьте файл решения, сохранив экспортируемый API.
3. Повторите запуск и добавьте собственный пример из описания.
4. Запишите объяснение механизма в тренажёре; там доступны три последовательные подсказки.

Проверки выполняют функции на новых данных. TypeScript-задачи компилируют отдельного потребителя, Angular-задачи используют настоящие API установленных пакетов. Файлы эталонов и отчётов отделены от решения ученика.

`starter.mjs` — сохранённый исходный образец для проверки платформы. Работайте в `solution.mjs`: решённое упражнение не должно ломать общие тесты курса.
