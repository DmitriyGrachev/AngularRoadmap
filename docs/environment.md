# Окружение и сведения о рабочем проекте

## Проверенная учебная среда

| Инструмент | Версия |
|---|---|
| Node.js | 22.23.2 |
| npm | 10.9.8 |
| Angular / CLI / compiler | 22.2.3 |
| TypeScript | 6.0.3 |
| RxJS | 7.8.2 |
| Java | Amazon Corretto JDK 21.0.12.1 |
| Vitest | 5.0.5 |
| jsdom | 27.4.0 |
| Playwright | 1.64.1 |

Версии npm-зависимостей закреплены в `package-lock.json`. Установка проверена через `npm.cmd ci` в отдельной чистой копии. Глобальный Angular CLI и Maven не требуются.

Для Java API используется source launcher JDK 21 и Gson 2.13.2, скачиваемый из Maven Central с проверкой закреплённого SHA-256. Сайт курса не зависит от Java-процесса.

Учебная среда работает на Angular 22.2.3 / TypeScript 6.0.3. Целевой рабочий стек — Angular 21.2.18 / TypeScript 5.9.3. Это разные окружения: команды установки курса не предназначены для WEBC. Примеры адаптации используют standalone, `signal`, `computed`, DI и RxJS — без требования перенести новые API Angular 22 в рабочий код. Совместимость всего учебного проекта с Angular 21 отдельным запуском не проверялась.

## Рабочий профиль PL — уточнён 21 октября 2026

Источник — предоставленная вами проверка `package.json`, lock-файлов, установленных зависимостей и исходников. В этой адаптации рабочие репозитории повторно не проверялись. Подробности ниже относятся прежде всего к PL2.2; одинаковые версии PL2.1 не означают полного совпадения архитектуры всех экранов.

| Зависимость | PL2.2 / PL2.1 | PL1.26 |
|---|---|---|
| Angular Core | 21.2.18 | 19.2.14 |
| Angular CLI | 21.2.19 | 19.2.2 |
| Material / CDK | 21.2.14 | 19.2.2 |
| TypeScript | 5.9.3 | 5.8.3 |
| RxJS | 7.8.2 | 7.8.2 |

`^21.2.18` в package.json — разрешённый диапазон, а таблица отражает версии из lock-файла на момент проверки. При работе с другой веткой сверяйте её lock-файл, инструкции запуска и CI. Не обновляйте зависимости, чтобы повторить пример курса.

- **Архитектура:** standalone, запуск через `bootstrapApplication`. В проверенных основных `WEBC/src` собственных NgModules и `standalone: false` не найдено. Отсутствие `standalone: true` само по себе не означает NgModule.
- **Состояние:** собственный `StoreService` на `signal` и `computed`; RxJS для запросов и событий, в том числе `EventsService`. NgRx в проверенном PL2.2 не найден.
- **UI PL2.2:** Material / CDK (меню, уведомления, drag-and-drop, фокус), Bootstrap 5.3.8, ng-bootstrap 20.0.0, ngx-bootstrap 21.2.1 и собственные таблицы, деревья, карта, редакторы. PrimeNG не найден. ng-bootstrap и ngx-bootstrap — разные библиотеки; для изменения выбирайте ту, которую уже использует нужный экран.
- **Графики PL2.2:** ECharts 6.1.0 / ngx-echarts 21.0.0. Изучать при задаче на графики, после компонентов, входных данных и жизненного цикла.
- **Существующие подходы:** есть поддержка прежних параметров URL и базовый класс с ручной отпиской. Standalone не отменяет наследование и необходимость разбираться в очистке подписок.

Ориентиры из вашей проверки (пути относительно `PL2.2/WEBC`): `src/main.ts`, `src/app/store/store.service.ts`, `src/app/services/events.service.ts`, `src/app/common/components/map/base-map-component.ts`, `src/app/main/map/map.component.html`, `src/app/common/simple-table/simple-table.component.ts`, `src/app/common/components/subscriptions.component.ts`, `src/app/common/components/service/services-workspace.utils.ts`. Номера строк могут измениться; ищите символы через IDE. Рабочий код в учебную платформу не копируется.

## Как это меняет обучение

Базовая последовательность и её 90 часов сохраняются. С 28 октября добавлен второй этап недель 7–12 ещё на 90 часов: архитектура frontend, сложный UI, RxJS, контракты с Java, безопасность, тестирование и доставка. Пользователь подтвердил уверенное владение Spring Boot, JPA, SQL и тестами; эти основы не повторяются. Связь с PL входит в время разбора примеров, а углублённое чтение рабочего репозитория — в резерв 0–5 часов в неделю.

| Когда | Акцент и наблюдаемый результат |
|---|---|
| Недели 1–2 | HTML/CSS/JS, события, неизменяемое обновление массивов, async/await, строгий TS. Найти класс, шаблон и стиль одной рабочей страницы; пока не читать весь StoreService. |
| Уроки w3-01, w3-03, w3-04 | Standalone и imports; состояние вкладки через сервис Signals; кто создаёт сервис и кто его разделяет. Объяснить путь click → set → computed → шаблон. |
| Урок w4-04 | Связь RxJS и Signals: отмена устаревшего чтения, ошибка внутри запроса, один владелец подписки, `toSignal` / `async` / `takeUntilDestroyed`. Не заменять события состоянием механически. |
| Неделя 5 | Типизированные Reactive Forms, ошибки API, сохранение ввода. Фактический подход к формам PL пока не подтверждён; наличие Signals не доказывает использование Signal Forms. |
| Урок w6-01 | Читать реальную standalone-страницу, custom table, Material/CDK и Bootstrap-обёртки. Проследить контракт компонента и существующую отписку. NgModules — справка для чтения библиотек, не основной путь PL. |
| При первой задаче | Повторить соглашения ближайшего рабочего экрана; проверить прямую ссылку, Back, пустой ответ, ошибку и повторное открытие страницы. Графики и drag-and-drop — по необходимости. |
