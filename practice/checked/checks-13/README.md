# Связать подписку с настоящим DestroyRef

Урок w3-04, около 25 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

Подписка может пережить компонент. takeUntilDestroyed завершает её при уничтожении DestroyRef владельца. Явная передача DestroyRef позволяет вызывать оператор вне injection context. Как детерминированное освобождение ресурса в Java, отписка запускает cleanup; garbage collection сама по себе не гарантирует этого, потому что источник удерживает callback.

### Контракт API

watchValues(source$,destroyRef,onValue) использует takeUntilDestroyed(destroyRef) из @angular/core/rxjs-interop, передаёт next в onValue и возвращает Subscription. После destroy больше нет callback, teardown выполняется один раз, subscription.closed=true. Уже уничтоженный DestroyRef вообще не допускает подписку источника. Проверка создаёт настоящий EnvironmentInjector, получает его DestroyRef и уничтожает injector.

### Пример и новая проверка

Источник выдаёт 1, затем destroy, затем пытается выдать 2: обработчик видит [1]. Новый пример: уничтожьте владельца до watchValues и посчитайте подписки источника.

## Условия приёмки

- Подписка связана с реальным жизненным циклом Angular.
- После destroy нет значений и ресурса источника.
- Уже уничтоженный владелец не запускает источник.
