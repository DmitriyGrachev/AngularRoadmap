# Обновить одну заявку без мутации

Урок w1-04, около 25 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

Массив хранит ссылки на объекты. Spread массива не копирует элементы: присваивание item.status меняет старое состояние. Создавайте новый объект только для изменённой записи, сохраняя ссылки остальных. Как и в Java, две переменные могут ссылаться на один объект; поверхностная копия не равна clone всего графа.

### Контракт API

updateStatus(items,id,status) принимает заявки с уникальными строковыми id и полями title/status (OPEN, IN_PROGRESS, DONE). Измените только совпавшую запись, сохранив порядок и остальные поля. Вход может быть frozen. Если id отсутствует или статус уже равен новому, верните тот же массив по ===.

### Пример и новая проверка

Для [Q-7 OPEN,Q-9 DONE] смените Q-7 на DONE: ссылка Q-9 остаётся прежней. Новый пример: отсутствующий X-99 должен вернуть исходный массив.

### Работа

Из корня проекта выполните `npm.cmd run learn -- check checks-01`. Редактируйте только `practice/checked/checks-01/solution.mjs`. Сначала запишите прогноз или собственную попытку в тренажёре. Отчёт сохраняется в practice/reports и не отмечает урок освоенным автоматически.

## Условия приёмки

- Меняется только найденная запись; порядок и дополнительные поля сохраняются.
- Вход не мутирует; неизменённые объекты сохраняют ссылки.
- Пустой список, отсутствующий id и прежний статус возвращают исходную ссылку.

## Проверка

1. Запустите исходный вариант и прочитайте конкретные провалы.
2. Исправьте файл решения, сохранив экспортируемый API.
3. Повторите запуск и добавьте собственный пример из описания.
4. Запишите объяснение механизма в тренажёре; там доступны три последовательные подсказки.

Проверки выполняют функции на новых данных. TypeScript-задачи компилируют отдельного потребителя, Angular-задачи используют настоящие API установленных пакетов. Файлы эталонов и отчётов отделены от решения ученика.

`starter.mjs` — сохранённый исходный образец для проверки платформы. Работайте в `solution.mjs`: решённое упражнение не должно ломать общие тесты курса.
