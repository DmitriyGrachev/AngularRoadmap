# Добавить серверные ошибки, сохранив ввод

Урок w5-04, около 25 минут. Может заменить часть ручной практики урока.

## Механизм и мост из Java

Пересоздание формы после 422 теряет ввод, touched и dirty. setErrors заменяет весь объект ошибок, поэтому server нужно объединить с текущими ошибками. Java validation map относится к DTO запроса, но на клиенте имена надо сопоставить с существующими controls. Серверный ответ не должен стирать локальный minlength.

### Контракт API

applyServerErrors(form,errors) возвращает undefined. form — настоящий FormGroup с плоскими controls; errors — Record<string,string[]> из проверенного ответа. Для существующего control и непустого списка установите {...currentErrors,server:[...messages]}. Не меняйте значения, dirty/touched или другие controls. Неизвестное поле и пустой список игнорируются. Повторная ошибка заменяет только server. Очистка при новом вводе вне объёма функции.

### Пример и новая проверка

При title.errors={minlength:...} серверный ["Занято"] добавляет server. Новый пример: отсутствующий archived не должен создавать control или вызывать исключение.

### Работа

Из корня проекта выполните `npm.cmd run learn -- check checks-10`. Редактируйте только `practice/checked/checks-10/solution.mjs`. Сначала запишите прогноз или собственную попытку в тренажёре. Отчёт сохраняется в practice/reports и не отмечает урок освоенным автоматически.

## Условия приёмки

- Сообщения доступны через control.errors.server.
- Локальные ошибки и ввод сохраняются.
- Пустые списки и неизвестные поля игнорируются.

`starter.mjs` — сохранённый исходный образец для проверки платформы. Работайте в `solution.mjs`: решённое упражнение не должно ломать общие тесты курса.
