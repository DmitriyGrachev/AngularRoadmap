# bug-02: Back меняет адрес, но оставляет старый фильтр

Связанный урок: [w3-05](../../../content/lessons/w3-05.md). Около 35 минут; упражнение может заменить часть ручной практики урока.

Симптом: прямой URL с OPEN работает, но переход к DONE и Back оставляют несогласованный фильтр. Запустите node practice/bug-lab/bug-02/repro.mjs: один экземпляр получает OPEN → DONE → OPEN, как при смене query parameters. До правки наблюдения равны OPEN → OPEN → OPEN. Исправьте чтение и освобождение подписки. Выбор фильтра должен записывать URL и сбрасывать страницу.

## Запуск из корня проекта

```powershell
node practice/bug-lab/bug-02/repro.mjs
npm.cmd run learn -- check bug-02
```

Сценарий работает без сайта, dev server и Java API с установленными зависимостями проекта. Исходный дефект намеренно завершает repro с AssertionError и ненулевым кодом. После исправления сценарий завершается успешно. Полная проверка создаёт отчёт версии 1 для учебного сайта.

Редактируйте только `solution.mjs`. `starter.mjs` сохраняет исходную поломку для проверки качества задания и не зависит от вашего решения. Существующее приложение ученика не используется и не переписывается.

## Контракт

createFilters(route, router) возвращает { status: Signal, select(status), destroy() }. route предоставляет snapshot.queryParamMap и queryParamMap; router — navigate. Оболочка компонента вызывает destroy.

## Критерии результата

- status() отражает каждый queryParamMap без создания новой модели.
- Неизвестный или отсутствующий статус означает ALL.
- select вызывает navigate с status, page: 1 и queryParamsHandling: "merge"; status меняется после нового URL.
- После destroy параметры больше не меняют signal.

## Диагностика

Перед изменением запишите ожидаемое и фактическое поведение, гипотезу причины и эксперимент, различающий две возможные причины. После исправления запустите полную проверку, а не только один repro. Три последовательные подсказки и объяснение находятся в тренажёре; сначала сохраните собственную попытку.

## Новый регрессионный пример

Регрессионная задача: начните с DONE/page=4/q=сеть, выберите OPEN и вернитесь назад. Проверьте статус, сброс page при выборе и сохранение q в рабочем приложении. Автопроверка подтверждает контракт navigate, а не сам браузер.
