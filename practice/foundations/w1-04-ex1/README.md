# Данные списка заявок

Редактируйте только `solution.mjs`. Реализуйте две функции:

- `filterIssues(issues, status)` возвращает новый массив заявок с указанным статусом, сохраняя исходный порядок. Статусы: `OPEN`, `IN_PROGRESS`, `DONE`; при отсутствии совпадений — `[]`.
- `labelIssues(issues)` возвращает строки `id: title`, например `A-1: Исправить поиск`. Пустой вход даёт `[]`.

Не изменяйте исходный массив и его объекты. Пример входа: `[{ id: 'A-1', title: 'Исправить поиск', status: 'OPEN' }]`.

Из корня курса выполните:

```powershell
npm run learn -- check w1-04-ex1
```

Четыре условия: `filter-open`, `immutable-input`, `empty-list`, `labels`. Нетронутая заготовка должна завершиться с `failed`; это ожидаемо. Исправьте функции и повторите команду. Отчёт появится в `practice/reports/`: импортируйте его на странице «Прогресс». Отчёт отражает состояние кода во время запуска; после изменения кода проверку нужно повторить.

После успеха объясните, почему `filter` создаёт новый массив, но сохраняет ссылки на выбранные объекты. Затем самостоятельно получите подписи только заявок `IN_PROGRESS`, объединив обе функции.
