# middle-01 — Ограничить параллелизм и сохранить порядок

## Механизм

Promise.all наблюдает переданные promises; операции обычно запускаются при их создании. Сам Promise.all не ограничивает число операций. Общий индекс раздаёт следующую работу свободному worker; результаты пишутся по исходному индексу. Аналогия с bounded executor полезна только для ограничения нагрузки: JavaScript здесь не создаёт CPU-потоки.

### Контракт API

Экспортируйте `async mapConcurrent(items, limit, worker)`. `items` — массив, `worker(item,index)` возвращает значение или Promise. Результат — Promise массива значений в исходном порядке. Одновременно выполняются не более `limit` работ. `limit` — положительное целое; иначе Promise отклоняется с RangeError, даже для пустого массива. Пустой ввод даёт []. Синхронный throw и rejected Promise отклоняют итог с тем же объектом ошибки. После того как ошибка замечена, новые работы не запускаются; уже запущенные могут завершиться. Ввод не изменяется. Отмена уже начатой работы в этот контракт не входит.

### Пример и новая проверка

При limit=2 сначала запускаются a и b. Завершение b разрешает c, хотя a ещё выполняется. Для завершения b,c,a итог всё равно [A,B,C]. Новый пример: первая операция бросает ошибку, в очереди ещё десять — они не должны стартовать после обнаружения отказа.

## Критерии

- Ни один момент не содержит больше limit активных работ.
- Порядок результата совпадает с входом, независимо от порядка завершения.
- Плохой limit и ошибка worker обрабатываются без запуска остатка очереди.

## Подсказки по порядку

1. Не создавайте Promise для каждого элемента заранее.
2. Несколько async workers могут брать следующий индекс из общей переменной.
3. Запишите результат по индексу; общий флаг остановит запуск после catch.

## После своей попытки

Ограничивается число незавершённых операций, а не размер итогового массива. Проверка использует управляемые promises без ожидания реального времени. Это не проверка пропускной способности сети: перенос в приложение требует AbortSignal и наблюдения за отменой HTTP.
